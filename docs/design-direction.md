# Supplier Recall visual direction

Designing a practical sourcing workbench for a small online store. The primary interaction is a comparison table with inspectable evidence; a chronological memory column makes learned context visible.

Live Refero tools are unavailable. Grounding uses the installed refero-design typography, craft-details, and anti-ai-slop references and the approved product workflow.

Reference lock: white workspace; light neutral-gray canvas; charcoal type; emerald used for primary actions and positive evidence; amber for unresolved questions; compact sans-serif navigation and tabular price figures. No decorative illustrations, gradients, oversized marketing headlines, or independent cards for every metric.

| Decision | Source | Role / reason |
|---|---|---|
| One system sans-serif family, 400/500/600 weights | Typography guide | Readable operational text without remote font requests |
| Comparison rows and section dividers | Anti-ai-slop + approved quote comparison | Columns allow scanning the same attributes across suppliers |
| Evidence panel and memory timeline | Approved learning-loop demo | Shows why the recommendation changed and the supporting records |
| Visible labels, focus-visible rings, status copy | Craft-details guide | Keyboard operation and recovery while writes are pending |
| Three supplier monograms, small line icons | Anti-ai-slop guide | Fast identity recognition, no decorative imagery needed |

Tokens: canvas #f7f8fa; surface #ffffff; text #192521; secondary #58645f; border #e4e9e6; primary #147d59; primary-tint #eaf6ef; warning #94611b; warning-tint #fff7e8. Corner radius 8–12px for interactive panels; low/no shadows. 12/14/16/20/28/36px type scale. 8px spacing grid. Source links remain visible, not encoded only by color. Workbench collapses to one column on mobile.
